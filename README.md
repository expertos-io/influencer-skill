# Influencer · Crear contenido

Skill para Codex, Claude Code y cualquier agente: crea fotos y vídeos con tu influencer de IA desde el chat.

- Conecta tu cuenta de tu comunidad (con su dirección web).
- Recrea fotos y carruseles de Instagram con tu influencer.
- Recrea reels y vídeos con tu influencer.
- Todo con tus créditos.

## Instalar

Pídeselo a tu agente:

> Instala la skill de https://github.com/expertos-io/influencer-skill: clónala en `~/.codex/skills/influencer-crear-contenido` (si usas Claude Code, en `~/.claude/skills/influencer-crear-contenido`). Cuando esté instalada, úsala para conectarme a mi comunidad.

O a mano:

```bash
git clone https://github.com/expertos-io/influencer-skill.git ~/.codex/skills/influencer-crear-contenido
```

Para actualizarla: `git -C ~/.codex/skills/influencer-crear-contenido pull`.
